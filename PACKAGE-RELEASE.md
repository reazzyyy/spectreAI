# Релиз пакета документации — 2026-10-27

## Содержимое

Обновлены журнал решений и связанные спецификации после согласования владельцем продукта пакета № 2.

## Зафиксировано

- Next.js + NestJS + PostgreSQL + Prisma + Redis/BullMQ.
- Сущности `Client` и `Matter` в MVP; связь с `Workspace` может быть необязательной.
- Лимит файла 25 МБ; PDF/DOCX/TXT; не более 10 файлов в операции.
- AIJob: `queued`, `running`, `succeeded`, `failed`, `cancelled`, `timed_out`.
- Временный административный доступ — до 60 минут, отдельное разрешение `admin_grant:approve`, одобрение только другим участником.
- Инфраструктура приложения, основная БД и файловое хранилище — в России.
- OpenAI API — целевой провайдер; конкретная модель пока не выбрана. До разрешения передачи реальных клиентских данных использовать `SyntheticAIProvider` с синтетическими данными.
- PostgreSQL + `pgvector` и полнотекстовый поиск PostgreSQL.
- Удаление активных и производных данных до 24 часов; резервные копии 35 дней; цель хранения аудита 1 год; RPO ≤ 24 часа, RTO ≤ 8 часов.
- OCRmyPDF + Tesseract — гипотеза, требующая тестирования.

## Важное ограничение

Документы описывают согласованные требования и проектные правила, но не доказывают реализацию или прохождение юридического/безопасностного аудита. Конкретная модель OpenAI, хостинг-провайдер, правовая допустимость передачи данных и OCR-движок остаются открытыми.
