# Изменения пакета документации — пакет 3

Дата: 2026-10-27

Основано на актуальном архиве `cursor.zip` и решениях, явно подтверждённых владельцем продукта.

## Зафиксировано
- Подтверждено: production-инфраструктура должна размещаться в России. Это включает приложение, основную БД, файловое хранилище и карту размещения логов, индексов, резервных копий и производных данных. Конкретный российский провайдер остаётся открытым.
- Подтверждено: целевой внешний AI-провайдер — OpenAI API; конкретная модель остаётся открытой. Вызовы идут через заменяемый AI Gateway/adapter.
- До отдельного разрешения передачи данных в OpenAI API применяется `SyntheticAIProvider` с синтетическими данными; реальные клиентские документы запрещено отправлять во внешний API.
- Синхронизированы формулировки по инфраструктуре в `docs/decisions-log.md`, `docs/23-deployment-and-infrastructure.md`, `docs/adr/ADR-0001-data-residency-and-model-provider.md` и `README.md`.
- Исправлены дублирующий идентификатор `INFRA-012` и устаревшая формулировка, будто регион production ещё не выбран.

## Что осталось открытым
- Конкретный российский инфраструктурный провайдер и схема развёртывания.
- Конкретная модель OpenAI и её лимиты/цена/качество.
- Юридическая и договорная оценка передачи допустимых категорий данных в OpenAI API. До её завершения — только Synthetic.
- OCRmyPDF + Tesseract остаётся гипотезой до тестирования.

Пакет содержит документацию и инструкции; он не означает, что приложение реализовано или прошло юридический/безопасностный аудит.
