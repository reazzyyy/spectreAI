## 1. Сравнение

### 1.1. Функции

| Направление | Нейро Юра (заявлено на лендинге) | spectreAI (целевое MVP, D-004 + docs/00) | Комментарий |
|---|---|---|---|
| Чат с ИИ | Чат, анализ документов, история обращений | Chat: диалоги, история, выбранный контекст (docs/32) | Сходно по форме |
| Работа с документами клиента | Проверка документов, создание, сравнение редакций, саммари, «любые форматы» | Docs: загрузка PDF/DOCX/TXT, обработка, статус, поиск (D-010/D-017) | У spectreAI — **свои документы клиента** в приватном хранилище; у Нейро Юры — и свои, и чужая экспертная база |
| Поиск / Research | Быстрые ответы в поиске + нейрообзоры судебной практики | Research по документам клиента + утверждённым источникам (до O-006) | У Нейро Юры — собственная платная база НПА/судебки; у spectreAI это OPEN (O-006) |
| Черновики | Создание документов по промпту | Drafts: подготовка/редактирование/версии/экспорт | Сходно |
| Командная работа | Не акцентируется | Workspace PERSONAL/TEAM, Client/Matter, роли OWNER/EDITOR/VIEWER (W-001…W-010) | **Ключевой дифференциатор spectreAI**, у Нейро Юры в лендинге почти не раскрыт |
| Человеческая экспертиза | Горячая линия экспертов, правовые заключения практиков/судей, журналы, обучение | Не входит в MVP | У spectreAI — только ИИ; контентная экспертиза отсутствует |
| База знаний / контент | 13 000 образцов, база НПА + судебка (ежедневно), справочник 3000+, журналы, видео, конструктор договоров | Нет собственной контентной базы | Принципиальная разница продуктовой модели |

**Вывод:** Нейро Юра = «справочно-правовая система + ИИ-слой поверх собственного контента». spectreAI = «приватная рабочая платформа + ИИ над документами клиента с гранулярным доступом». Прямой конкуренции по контенту нет; пересечение — только по «чат + анализ/создание документов».

### 1.2. Модель безопасности

| Аспект | Нейро Юра (заявлено) | spectreAI (подтверждённые решения) |
|---|---|---|
| Размещение | «Модель в защищённом периметре, утечка во внешний сервис исключена» | D-014: инфраструктура/БД/файлы в РФ; хостер O-003 (OPEN) |
| Модель/провайдер | Подразумевается self-hosted (нет внешней передачи) | D-015: целевой OpenAI API; **до O-002 только SyntheticAIProvider (D-012)**; self-hosting — будущая опция (D-003) |
| Изоляция tenant'ов | «Строгий ролевой контроль доступа» (без деталей) | W-020/ADR-0003: **PostgreSQL RLS обязателен** + NestJS authz; deny-by-default |
| Доступ админа к контенту | Не раскрыт | D-006/D-007/D-013/D-016: админ без grant не читает контент; grant ≤ 60 мин, независимое одобрение |
| Шифрование | «Сквозное шифрование» | at-rest + TLS in-transit (docs/security); «сквозного» не обещает |
| Аудит | «Регулярный аудит, стресс-тестирование» | D-021: аудит-лог 1 год без контента/промптов/секретов |
| Удаление | Не раскрыто | D-019/D-020: немедленная недоступность, purge ≤ 24 ч, бэкапы 35 дней |
| Классификация данных | Нет | D0–D4 (docs/03) |

**Вывод:** у spectreAI модель безопасности документирована детальнее и строже (RLS, deny-by-default, admin grant, lifecycle удаления). У Нейро Юры — декларации «периметра» без проверяемых деталей (какая модель, где физически, какие меры, сертификация).

## 2. Позиционирование и продающие тезисы (разбор механики лендинга)

Главный приём лендинга — **снятие ключевого возражения о галлюцинациях** юридического ИИ:

1. **Страх → решение.** «Универсальный ИИ опирается на непроверенные статьи, отменённые законы, неактуальную практику» → «Нейро Юра признаёт только экспертный контент. Не врёт в реквизитах, не придумывает нормы».
2. **Доверие через людей.** Фото + должности экспертов (главред, шеф-редактор, партнёр юрфирмы, юрслужба корпорации) + цитата главреда. Тезис: «обучали юристы-практики, а не технари».
3. **Контраст с «универсальным ИИ»** (читай ChatGPT/аналоги) — классическое отстройка от дженерик-моделей.
4. **Форматы ответа** как ценность: правовое заключение / таблица / чек-лист / протокол разногласий — «не пересказывает норму, а применяет её к ситуации».
5. **Безопасность как довод для юротдела:** периметр, шифрование, ролевой доступ, «невозможность копирования», аудит, «российские стандарты».
6. **Снятие рутины:** «берёт на себя рутину», список из 6 задач.
7. **Тарифная сетка** с ограничением «30 запросов/мес» в базовом — якорь апсейла.

**Что применимо к spectreAI (без копирования):**
- Механика «снятие возражения о галлюцинациях» применима, но аргумент spectreAI другой: не «своя экспертная база», а **«показываются только реально использованные и сопоставленные источники»** (docs/00) + проверяемые цитаты по DocumentVersion (D-034). Это уже сильный дифференциатор — его стоит вынести в лендинг.
- Усилить позиционирование командной работы: гранулярные права, client/matter, админ-без-чтения (D-006) — то, чего нет в заявленном Нейро Юре.

**Что НЕЛЬЗЯ переносить без подтверждения:** «сквозное шифрование», «невозможность копирования алгоритмов», «соответствует российским стандартам» — это заявления, требующие фактического подтверждения; spectreAI по канону обязан разделять «подтверждено» и «заявлено».

## 3. Проверка security-claims Нейро Юры против ADR-0003 / D-014

Проверяем каждый тезис лендинга против нормативных решений spectreAI (ADR-0003 = RLS, D-014 = размещение в РФ).

| Тезис Нейро Юры | Разбор | Сверка с spectreAI |
|---|---|---|
| «Модель развернута в защищённом периметре — утечка во внешний сервис исключена» | Подразумевает self-hosted модель без внешней передачи. Не подтверждено: какая модель, где физически, кто оператор. | **Сильнее текущего плана spectreAI** по резидентности модели (у spectreAI целевой — внешний OpenAI, D-015). Но D-003 допускает self-hosting в будущем; до этого — Synthetic (D-012). Это не отменяет O-002. |
| «Сквозное шифрование (при обучении и работе)» | E2E-шифрование для серверного ИИ технически противоречиво: сервер должен видеть plaintext для обработки. Скорее всего, речь о TLS + at-rest. | ADR-0003/D-014 шифрование «сквозное» **не требуют**. Канон spectreAI — at-rest + TLS in-transit (docs/security/encryption-and-secrets.md). Формулировку «сквозное» в наш лендинг не переносить. |
| «Строгий ролевой контроль доступа» | Декларация без модели ролей и без упоминания tenant-изоляции на уровне БД. | spectreAI строже и документированнее: W-005/W-006 + **RLS (ADR-0003)** + deny-by-default + admin grant. Это реальное преимущество для сравнения. |
| «Невозможность копирования алгоритмов» | Про защиту IP, **не** про безопасность данных. К ADR-0003/D-014 отношения не имеет. | Не является требованием spectreAI. |
| «Регулярный аудит, стресс-тестирование» | Термин «аудит» здесь = security testing/пентест, а не audit-log. | D-021 у spectreAI = технический аудит-лог событий (1 год), не подмена пентеста. Разные вещи. |
| «Соответствует российским стандартам» | Не конкретизировано: 152-ФЗ? ГОСТ? аттестация? Без этого — маркетинг. | **Ключевая точка.** `docs/03`: «размещение сервера в РФ само по себе не доказывает соответствие». D-014 = только размещение; 152-ФЗ и иные нормы требуют отдельной правовой проверки. Заявление «соответствует стандартам» без перечня стандартов не принимаем. |

**Итог по части 3.** Заявления Нейро Юры — маркетинговые, без проверяемой фактуры (модель, юрисдикция, меры, сертификация). spectreAI спроектирован строже на уровне **проверяемых** мер (RLS, deny-by-default, admin grant, lifecycle удаления), но **уступает** в одном потенциальном пункте: Нейро Юра декларирует self-hosted модель в РФ, тогда как spectreAI на MVP планирует внешний OpenAI API (заблокирован до O-002). Это не повод смягчать O-002, а повод зафиксировать self-hosting (D-003) как конкурентный аргумент, когда он будет реально доступен.

## Выводы и рекомендации

1. **Продукт:** прямого пересечения по контенту нет. Конкурентное преимущество spectreAI — приватная работа с документами клиента + командный доступ + гранулярные права + проверяемые источники. Нейро Юра выигрывает за счёт собственной экспертной базы и человеческой экспертизы, которой у spectreAI в MVP нет.
2. **Безопасность:** spectreAI документированнее и строже (RLS/ADR-0003, admin grant, deletion lifecycle). На лендинг стоит вынести именно эти проверяемые свойства, а не копировать «сквозное шифрование»/«невозможность копирования».
3. **Позиционирование:** использовать механику «снятие возражения о галлюцинациях», но с аргументом spectreAI — «источники показываются только если реально использованы и сопоставлены» (D-034).
4. **Прайс:** зафиксировать 154–287 тыс. ₽/год как рыночный ориентир для будущего пресейла; свою сетку не вводить до закрытия O-007/W-019.
5. **Открытые вопросы не трогать:** O-002, O-003, O-006, O-007 и др. остаются OPEN — этот документ ничего не закрывает.
