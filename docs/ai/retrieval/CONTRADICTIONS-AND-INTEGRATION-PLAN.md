**Статус:** WORKING / сверка при интеграции (2026-11-16)  
**Назначение:** зафиксировать потенциальные расхождения и как их читать. Не повышает PROPOSED до CONFIRMED.

## 1. Нет жёсткого конфликта со статусами D/O/H

Пакет сам запрещает менять D/O/H и назначать новые официальные ID. Формулировки согласованы с **D-012**, **D-018**, **O-002**, **O-006**, Gate B, **FILE-009**, **W-020**.

## 2. Зоны внимания (не «ошибки», а границы чтения)

### 2.1. ParadeDB BM25

- **Пакет:** сравнить PostgreSQL FTS и ParadeDB (`TO_VALIDATE`).
- **Канон:** D-018 = PostgreSQL FTS + pgvector.
- **Правило:** до нового CONFIRMED-решения в `decisions-log` реализация и production-зависимость — только PostgreSQL FTS. ParadeDB допустим лишь как изолированный benchmark.

### 2.2. Embedding-кандидат Qwen3

- **Пакет:** кандидат `TO_VALIDATE`.
- **Канон:** Gate B / модель OPEN; `docs/33` запрещает фиксировать vector schema до выбора dimensions.
- **Правило:** не писать миграции с конкретной размерностью «под Qwen3» без закрытия Gate B.

### 2.3. Два контура RAG

| Контур | Канон / пакет | Фокус MVP |
|---|---|---|
| User documents | `docs/17`, `docs/33`, Phase 6 | DocumentVersion, chunks, FTS/vector по ACL org/workspace |
| Legal norms / research | `docs/18`, `docs/ai/retrieval/` | Exact lookup, temporal editions, O-006 sources |

Не смешивать в одной Prisma-модели без отдельного решения. Логические «collections» в пакете — политики, не требование отдельных БД.

### 2.4. OCR

- **Пакет:** OCR «по необходимости» для сканов.
- **Канон:** клиентские сканы — **D-031** failed до OCR; OCR tool — **H-002**; разрешение — **O-004**.
- **Правило:** пакет не отменяет D-031 для пользовательских документов. OCR нормативных корпусов — отдельное согласование + лицензия источника (**O-006**).

### 2.5. Новые сущности LegalAct*

- **Пакет:** логическая модель PROPOSED / TO_VALIDATE.
- **Канон:** `docs/06` / Prisma AS-IS не содержат LegalAct*.
- **Правило:** не создавать таблицы «по документу 03» до O-006 и утверждённой схемы; при появлении схемы — ADR/журнал + тесты ACL/RLS.
