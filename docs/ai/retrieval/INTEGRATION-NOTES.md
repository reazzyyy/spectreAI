# Интеграция пакета Retrieval Engine

**Дата:** 2026-11-16  
**Ветка:** `docs/ai-retrieval-package-integration`  
**Версия пакета:** 0.2 (повторная интеграция поверх 0.1)  
**Статус:** документационная интеграция; код Retrieval Engine / LegalAct schema **не** реализуется этим пакетом.

Повторная загрузка v0.2 заменила тексты пакета и удалила файлы сверки первой интеграции. Этот файл восстановлен и обновлён под v0.2.

## Что добавила версия 0.2

- Три логических компонента: `LegalProvisionTextVersion`, `AmendmentOperation`, `ApplicabilityRule`. Это не три обязательные таблицы Prisma.
- Контракт правила: `effectiveFrom/To`, `relationPeriod`, `conditionAsOf`, условия только с `conditionMode: "ALL"`.
- Трёхзначные факты: `unknown` не равен `false`; при нехватке фактов — `insufficient_facts` или `manual_review`.
- Универсальный Rule Engine, вложенные AND/OR/NOT и скрипты в MVP не входят.
- Кейсы T-01 (44-ФЗ / 624-ФЗ), T-02 (НК РФ / 611-ФЗ), T-03 (ГК РФ ст. 453 / 347-ФЗ) в `09-temporal-evaluation-cases.md`.
- Следующий шаг пакета: сверка с каноном → юридическая проверка формулировок → parser contract → exact lookup. Benchmark FTS/vector — после этого.
