# 00. Обзор проекта

Версия: 0.1.0.

## Подтверждённые решения
- **CONFIRMED (D-001):** целевой рынок — Россия.
- **CONFIRMED (D-002):** аудитория — юридические фирмы и команды.
- **CONFIRMED (D-003):** в MVP используются модели через API; архитектура должна допускать self-hosting в будущем.
- **CONFIRMED (D-004):** MVP включает chat, docs, research, drafts и workspace.
- **CONFIRMED (D-005):** Harvey AI — ориентир продуктового подхода и визуального направления, не объект буквального копирования.

Полный перечень D-006–D-022 и OPEN/HYPOTHESIS — только в `docs/decisions-log.md`.

## Видение
Профессиональная AI-платформа, где юридические команды работают с документами, исследуют правовые вопросы, готовят проекты текстов и сохраняют результаты в контексте команды, клиента или дела. Ценность — не только чат, но управляемый контекст, источники, права доступа и совместная работа.

## MVP
1. **Chat:** диалоги, история, выбранный контекст.
2. **Docs:** загрузка, приватное хранение, обработка, просмотр статуса, поиск.
3. **Research:** поиск по доступным документам и отдельно утверждённым юридическим источникам.
4. **Drafts:** подготовка, редактирование, версии и экспорт текстов.
5. **Workspace:** организация работы команды и группировка материалов.

Не включать без отдельного решения: автономную отправку/подписание документов, обучение моделей на данных клиентов, публичные ссылки на документы, интеграции с правовыми базами без проверки лицензий и условий, сложную CRM и биллинг.

## Предварительные роли
- Администратор организации / owner / admin / member (детали матрицы — `07`; многие ячейки ещё **OPEN**).
- Гость/внешний участник — **OPEN**.

**CONFIRMED по доступу к содержимому (D-006/D-007/D-013/D-016):** админ не читает содержимое автоматически; временный grant только после независимого `admin_grant:approve`, TTL ≤ 60 мин. Остальная матрица ролей — до утверждения в журнале.

## Основные сценарии
### Анализ документа
Пользователь загружает файл → сервер проверяет доступ, тип и размер (**D-010/D-017**) → файл сохраняется приватно → фоновый процесс извлекает текст и индексирует (**D-018**) → пользователь задаёт вопрос → сервер проверяет доступ и выбирает разрешённые фрагменты → вызов через AI Gateway (**Synthetic до O-002**, D-012) → интерфейс показывает результат и проверяемые источники.

### Подготовка текста
Пользователь задаёт задачу и контекст → сервер собирает разрешённые источники → модель создаёт черновик → юрист редактирует → система сохраняет версию → экспорт выполняется только по явному действию.

### Командная работа
Пользователь видит только разрешённые workspace. Изменения ролей и отзыв доступа применяются на backend, в поиске, скачивании, экспорте и фоновых задачах.

## Принципы
- Конфиденциальность по умолчанию.
- Минимально необходимые права и данные.
- Юрист проверяет результат ИИ.
- Источники показываются только если они действительно использованы и сопоставлены.
- Передача данных внешнему поставщику контролируется политикой.
- Неизвестные решения явно помечаются.

## Предлагаемые метрики
Доля успешной обработки файлов; время индексации; задержка и ошибки модели; стоимость по типам задач; качество ссылок на источники; доля повторных генераций. Числовые цели и нагрузка — **OPEN**.


## Решения, подтверждённые 2026-10-27 (пакеты 2–3)

- **D-008:** стек MVP — Next.js, NestJS, PostgreSQL, Prisma, Redis/BullMQ.
- **D-009:** сущности Client и Matter; связь с Workspace может быть необязательной.
- **D-010 / D-017:** PDF, DOCX, TXT; 25 МБ на файл; max 10 файлов за операцию.
- **D-011:** статусы AIJob — `queued|running|succeeded|failed|cancelled|timed_out`.
- **D-012 / D-015:** целевой AI — OpenAI API (модель **O-001** OPEN); до **O-002** — только SyntheticAIProvider.
- **D-013 / D-016:** admin grant TTL ≤ 60 мин; `admin_grant:approve` назначает owner; self-approve запрещён.
- **D-014:** размещение инфраструктуры/БД/файлов (и учёт копий) в России; хостер — **O-003**.
- **D-018:** PostgreSQL FTS + `pgvector`.
- **D-019 / D-020 / D-021 / D-022:** удаление активных/производных ≤ 24 ч; бэкапы 35 дней; цель аудита 1 год; RPO ≤ 24 ч / RTO ≤ 8 ч.
- **H-002:** OCRmyPDF + Tesseract — гипотеза. Подробности — `docs/decisions-log.md`.
