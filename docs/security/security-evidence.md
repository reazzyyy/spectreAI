# Реестр свидетельств безопасности

**Статус: PROPOSED**

| ID | Контроль | Требуемое свидетельство | Владелец | Статус |
|---|---|---|---|---|
| E-001 | Tenant isolation | Автоматические негативные API-тесты | Назначить | Не проверено |
| E-002 | ACL для файлов | Тесты download/export | Назначить | Не проверено |
| E-003 | Admin content grant | Тесты request/approve/TTL/revoke | Назначить | Не проверено |
| E-004 | Запрет реального AI до O-002 | Тест/конфигурация provider gateway | Назначить | Не проверено |
| E-005 | Отсутствие контента в логах | Тест логирования и ревью | Назначить | Не проверено |
| E-006 | Удаление производных данных | Интеграционный тест lifecycle | Назначить | Не проверено |
| E-007 | Backup restore | Протокол восстановления | Назначить | Не проверено |
| E-008 | Зависимости | Отчёт dependency scan | Назначить | Не проверено |
| E-009 | Регион размещения | Конфигурация и договор поставщика | Назначить | Не проверено |
| E-010 | Реакция на инцидент | Настольное учение/протокол | Назначить | Не проверено |

Не помещать в этот реестр реальные секреты, полные клиентские документы или чувствительные детали эксплойтов. Ссылки на внутренние доказательства должны иметь собственные ACL.
