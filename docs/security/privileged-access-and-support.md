# Привилегированный доступ и поддержка

**Статус: PROPOSED**

**Норматив:** `docs/07-access-control-matrix.md` и решения **D-006**, **D-007**, **D-013**, **D-016**. Этот файл — operational summary; при расхождении приоритет у канона и журнала решений.

## Базовые требования
- Администратор организации управляет организацией, пользователями и настройками, но не получает автоматического доступа к содержимому документов.
- Чтение содержимого администратором возможно только после отдельного запроса и обязательного одобрения уполномоченным другим участником с правом `admin_grant:approve`.
- Самоодобрение запрещено. Если независимого согласующего нет, доступ не выдаётся.
- Временный грант должен иметь конкретную цель, область действия, заявителя, согласующего, время начала и окончания; TTL не более 60 минут.
- Доступ прекращается автоматически по истечении TTL; отзыв должен действовать немедленно.
- Все запросы, одобрения, отказы, чтения и отзывы должны попадать в audit log без записи содержимого документа.
- Break-glass доступ не входит в MVP.

## Обязательные проверки
- обычный администратор не может читать контент через UI, API, поиск, экспорт, download или фоновые задачи;
- заявитель не может сам одобрить запрос;
- грант не расширяется на другие документы/организации;
- истёкший или отозванный грант не работает через уже открытые сессии/URL;
- события аудита создаются для успешных и неуспешных попыток.
