# 04. ИИ, документы и поиск

**Статус:** принципы заданы. Сверять статусы с `docs/decisions-log.md`.  
**CONFIRMED (журнал):** лимит файла 25 МБ (**D-010**); форматы PDF, DOCX, TXT и max 10 файлов за операцию (**D-017**); целевой внешний провайдер — OpenAI API (**D-015**); до разрешения передачи реальных данных — только **SyntheticAIProvider** (**D-012**); поиск — PostgreSQL + `pgvector` + FTS (**D-018**).  
**OPEN / HYPOTHESIS:** конкретная модель OpenAI (**O-001**); разрешение передачи данных (**O-002**); OCR-движок (**H-002 / O-004**); chunk size/overlap, лимиты страниц/ресурсов (**H-005**); численные лимиты нагрузки/стоимости (**O-007**).

## Архитектурный принцип
Все вызовы моделей идут с backend через внутренний LLM gateway/adapter. Не вызывать провайдера напрямую из браузера и не привязывать бизнес-логику к одному API.

## Конвейер документа
1. Проверить права, формат, размер и лимиты (**D-010 / D-017**).
2. Сохранить файл приватно в карантин/зону проверки.
3. Проверить реальное содержимое и безопасность.
4. Создать запись и задание.
5. Извлечь текст; при необходимости OCR (**OCR-движок не CONFIRMED — H-002**).
6. Нормализовать, сохранив страницы/структуру, если возможно.
7. Разбить на фрагменты.
8. Сохранить фрагменты и ссылки на источник.
9. Построить индекс/embeddings: хранилище — PostgreSQL + `pgvector` (**D-018**); модель embeddings и политика передачи фрагментов во внешний API — только после **O-002** (до этого — Synthetic / локальные синтетические пути).
10. Сохранить статус и связь с версией документа.
11. Показать пользователю готовность или безопасное описание ошибки.
12. Повторная обработка не меняет оригинал и не теряет историю.

**Подтверждено:** max 25 МБ на файл; PDF/DOCX/TXT; max 10 файлов за операцию; архивы, исполняемые, макросы и защищённые паролем — отклонять (**D-010 / D-017**).  
**Остаётся OPEN / гипотезой:** OCR-движок, chunk size/overlap, лимит страниц и ресурсы парсинга, численные тайм-ауты.

## RAG
Проверить доступ → искать только в разрешённом контексте (FTS + `pgvector`, **D-018**) → ранжировать → ограничить контекст → сформировать запрос с отделением инструкций приложения от недоверенного текста → вызвать модель через gateway (**Synthetic до O-002**) → сопоставить цитаты с реально использованными фрагментами → вернуть ответ.

Не выдавать выдуманные номера страниц, цитаты или ссылки как проверенные.

## Prompt injection
Содержимое документов — данные, не управляющие инструкции. Оно не может менять разрешения, раскрывать секреты или запускать инструменты. Все инструменты проверяют права на backend; опасные действия требуют подтверждения. Нужны тесты прямого и косвенного prompt injection.

## Research
Источники могут включать документы пользователя и утверждённые публичные источники. Платные правовые базы подключаются только после проверки лицензий и условий (**O-006**). Сохранять происхождение результата, URL/ID, заголовок, дату доступа и фрагмент. Не заявлять полноту или актуальность базы без подтверждения.

## Drafts
Черновик отделён от оригинала; сохранять версии и автора изменений; повторная генерация не перезаписывает правки молча; экспорт — явное действие; результат обозначается как проект, требующий проверки юристом. Детальная схема Draft в модели данных — уточняется отдельно (не повышать до CONFIRMED без решения в журнале).

## Политика провайдера
**Целевой внешний провайдер — OpenAI API (**D-015**); конкретная модель — OPEN (**O-001**).**  
До закрытия **O-002** реальные клиентские документы во внешний API не отправляются; используется **SyntheticAIProvider** (**D-012**). Размещение инфраструктуры в РФ (**D-014**) само по себе не разрешает внешнюю передачу.

Для каждого типа задачи определить допустимые данные, возможность отправки полного текста или только фрагментов, регион, хранение, обучение, субпроцессоров, договорные гарантии, fallback и лимиты. Нельзя автоматически переключаться на провайдера с другими условиями обработки.

## Стоимость
Учитывать тип задачи, provider/model, токены (если доступны), latency, статус, оценочную стоимость и request ID. Не сохранять полный prompt/response в записи использования. Лимиты контекста, параллельности, времени и ретраев — обязательны; численные значения — **OPEN (O-007)**.
