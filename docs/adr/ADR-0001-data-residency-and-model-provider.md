# ADR-0001: Резидентность данных и внешние модели

Статус: частично **CONFIRMED** по журналу (**D-012**, **D-014**, **D-015**); передача реальных клиентских документов **заблокирована** до **O-002**. Дата: 2026-10-26; выравнивание с журналом: 2026-10-27.

## Контекст
Юридические документы могут содержать персональные данные, коммерческую тайну и конфиденциальные сведения. Вызов внешней модели может передавать часть содержимого сторонней организации и/или в другую юрисдикцию.

## Подтверждено
- MVP использует внешний API моделей; архитектура допускает локальные модели в будущем (**D-003**).
- Инфраструктура приложения, основная БД и файловое хранилище размещаются в **России** (**D-014**). Резервные копии, логи, индексы и прочие копии данных учитываются в карте потоков и мест хранения. Конкретный российский хостинг-провайдер — **OPEN (O-003)**; само требование размещения в РФ подтверждено.
- Основной внешний AI-провайдер — **OpenAI API** (**D-015**); конкретная модель — **OPEN (O-001)**. Доступ — через заменяемый внутренний AI Gateway/adapter.
- До разрешения передачи реальных данных (**O-002**) используется только **`SyntheticAIProvider`** с синтетическими данными (**D-012**). Размещение в РФ (**D-014**) само по себе **не** разрешает отправку во внешний API.

## Решение (нормативное для реализации)
1. Все вызовы проходят через backend LLM gateway.
2. До завершения **O-002** реальные клиентские документы не отправляются во внешний API; только Synthetic (**D-012**).
3. Для OpenAI (и любого будущего поставщика) фиксируются юрисдикция, регион, хранение запросов/ответов, обучение, субпроцессоры, удаление и договорные условия.
4. Политика задаётся по типам данных и задач.
5. Нельзя автоматически переключаться на провайдера с другими условиями.
6. В тестах и до разрешения передачи — синтетические документы.
7. Self-hosting обеспечивается заменяемым адаптером, но не обязателен для MVP.

## Последствия
Плюсы: быстрый запуск MVP на Synthetic, заменяемость модели, централизованный контроль передачи и расходов, ясная резидентность инфраструктуры в РФ.
Минусы: правовая/договорная проверка (**O-002**) до реальных данных; внешняя обработка у OpenAI может отличаться от места размещения приложения; self-hosting потребует инфраструктуры и эксплуатации.

## Условия закрытия передачи реальных данных (O-002)
Выбрана модель (O-001); изучены договоры OpenAI; определены передаваемые данные и основания; проверены локализация и трансграничная передача с учётом требований РФ; утверждены сроки хранения/удаления у провайдера; реализованы безопасные логи; пройдены тесты доступа. После закрытия O-002 — явное решение в `docs/decisions-log.md` перед переключением с Synthetic.
