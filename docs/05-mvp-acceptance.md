# 05. Критерии приёмки MVP

**Статус:** проект критериев приёмки; при расхождении приоритет у `docs/decisions-log.md`. Не превращать OPEN/HYPOTHESIS в CONFIRMED через этот документ.

## Общие
- Все данные защищены серверной авторизацией.
- Есть состояния loading, empty, error, forbidden, success.
- Секреты отсутствуют в репозитории и клиентском bundle.
- Документы не доступны публично (приватное хранилище).
- Миграции воспроизводимы; конфигурация окружения документирована.
- В отчёте указаны реально запущенные тесты.
- Стек реализации соответствует **D-008** (Next.js, NestJS, PostgreSQL, Prisma, Redis/BullMQ), если этап включает код приложения.
- Межорганизационная изоляция проверяется негативными тестами (подмена organization/workspace/document UUID).

## AI и провайдер (D-012 / D-015)
- До закрытия **O-002** все AI-вызовы с клиентским содержимым идут только через **SyntheticAIProvider**; реальные клиентские документы не отправляются в OpenAI API.
- UI явно обозначает synthetic/test режим, пока действует D-012.
- Целевой внешний провайдер — OpenAI API (**D-015**); конкретная модель (**O-001**) и разрешение передачи (**O-002**) не считаются закрытыми этими критериями.
- Размещение в РФ (**D-014**) не трактуется как разрешение внешней передачи данных.

## Chat
- Авторизованный пользователь может создать диалог и продолжить его.
- История доступна только разрешённым пользователям.
- Подмена ID не позволяет читать чужие диалоги.
- Ошибка провайдера/Synthetic не раскрывает секреты и не уничтожает ранее сохранённую историю.
- Длительные операции используют статусы **AIJob** только из **D-011**: `queued`, `running`, `succeeded`, `failed`, `cancelled`, `timed_out` (не `retry_wait`, не `completed` как статус job).

## Docs (D-010 / D-017 / D-019)
- Допустимые форматы: PDF, DOCX, TXT; max размер файла 25 МБ; max 10 файлов за операцию (**D-010 / D-017**).
- Архивы, исполняемые, макросодержащие и защищённые паролем файлы отклоняются.
- Подмена расширения не обходит проверку.
- Видны статусы обработки.
- Просмотр и скачивание требуют прав.
- Другая организация не может читать документ или найти его фрагменты (включая поиск/RAG).
- После подтверждённого удаления данные недоступны сразу; очистка основной системы, текста, индексов и производных — в пределах политики **D-019** (≤ 24 ч).

## Client / Matter / Workspace (D-009 / D-004)
- В MVP доступны сущности Client и Matter; связь с Workspace может отсутствовать (**D-009**).
- Пользователь видит только разрешённые workspace.
- Роли меняют только уполномоченные лица (конкретная матрица Owner/Admin — см. `07`, многие ячейки ещё OPEN).
- Отзыв доступа блокирует последующие запросы.
- Подстановка UUID другой организации не даёт доступа.

## Research
- Возвращаются только доступные источники.
- Каждый источник связан с сохранённым материалом.
- Отзыв доступа отражается в последующих поисках.
- При недостатке источников система не выдумывает ссылки.
- Внешние платные правовые базы — только после **O-006** (до этого research по пользовательским/утверждённым материалам).

## Drafts
- Черновик отделён от оригинала.
- Повторная генерация не теряет правки без предупреждения/подтверждения.
- Версии доступны только разрешённым пользователям.
- Экспорт не обходит доступ (**O-009** — форматы/права экспорта ещё OPEN; до решения не расширять экспорт молча).

## Admin temporary access (D-006 / D-007 / D-013 / D-016)
- Администратор не читает содержимое без отдельного grant.
- Запрос `pending` не даёт доступа.
- Одобряет только независимый участник с `admin_grant:approve` (назначает owner); self-approve запрещён.
- TTL предоставленного доступа ≤ 60 минут; без согласующего grant не выдаётся.
- Break-glass не входит в MVP.
- Цепочка request → decision → grant → use → expire/revoke аудируется без содержимого документов/промптов.

## Поиск / RAG (D-018)
- Используется PostgreSQL FTS + `pgvector` (**D-018**).
- ACL применяется до включения фрагментов в контекст модели.
- Prompt injection: содержимое документа не меняет права и не запускает инструменты.

## Обязательные негативные тесты
BOLA/IDOR; подмена organization/workspace/document ID; доступ через поиск/экспорт/кэш/очередь; prompt injection; недопустимый файл (формат/размер/архив); timeout провайдера/Synthetic; дублирование задания; отзыв доступа во время сессии; утечки через логи и ошибки; self-approve admin grant; TTL > 60 мин отклонён; AIJob со статусом вне D-011 отклонён.

## Блокеры production (не путать с блокерами локального Synthetic-scaffold)
- Не закрыты **O-002** (передача реальных данных в OpenAI) и при необходимости **O-001** (модель).
- Не выбран российский хостинг-провайдер (**O-003**), хотя размещение в РФ подтверждено (**D-014**).
- Не проведена согласованная правовая проверка передачи данных.
- Не проверено восстановление (цели **D-022**; процедура **H-004**).
- Нет прошедших межорганизационных тестов изоляции.
- Содержимое документов/промптов попадает в логи.
- Нет работающей процедуры удаления/отзыва доступа по **D-019 / D-007**.
- OCR для сканов без подтверждённого движка (**O-004 / H-002**) не объявлять production-ready.
