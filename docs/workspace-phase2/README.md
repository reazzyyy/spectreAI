### Особое уточнение A5/A7

Согласованный итог: содержимое Workspace читают его участники (для личного пространства — владелец; для командного — участники с ролью). Org Admin не имеет автоматического доступа к содержимому. Исключение — временный read-only `admin_grant` после запроса и независимого одобрения. Это соответствует действующим D-006/D-007/D-013/D-016; прежний ответ A5 «участники + Org Admin read-only» не применяется.

## 3. Важные ограничения

- Этот пакет описывает целевое поведение, а не утверждает, что оно уже реализовано.
- В текущем scaffold Workspace, приглашения, admin grant и RLS ещё не реализованы (сверить актуальный AS-IS перед работой).
- Не отправлять реальные клиентские данные во внешний AI до закрытия O-002; действует D-012 (`SyntheticAIProvider`).
- Сохранять лимиты D-010/D-017: PDF/DOCX/TXT, 25 МБ на файл, максимум 10 файлов за операцию.
- Сохранять D-011 статусы AIJob; не вводить `completed` или `retry_wait`.
- Сохранять D-019/D-020: после подтверждённого удаления данные сразу недоступны; очистка основной системы и производных данных — не более 24 часов; backups — 35 дней с replay deletion journal при restore.
- PostgreSQL RLS обязателен в MVP по решению C6 от 2026-11-03. RLS не заменяет бизнес-авторизацию NestJS.
- Экспорт описывается как целевая возможность, но его реализация не входит в MVP. O-009 остаётся открытым для окончательного согласования прав, форматов, лимитов и юридических условий.
